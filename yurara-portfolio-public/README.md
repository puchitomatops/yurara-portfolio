# 渡邉ゆらら ポートフォリオ

ChatGPT Sitesに依存しない、HTML・CSS・JavaScriptだけのポートフォリオです。

## ファイル

- `index.html` — 文章・リンク・画像などの内容
- `style.css` — 色、レイアウト、スマートフォン表示
- `script.js` — スクロールアニメーション
- `assets/` — 作品画像

## パソコンで確認する

`index.html`をダブルクリックするとブラウザーで開けます。VS CodeのLive Serverでも確認できます。

文章やリンクは `index.html`、色やレイアウトは `style.css`、アニメーションとBGMは `script.js` から編集できます。

## 公開する

フォルダー内の全ファイルを、そのままGitHub Pages、Netlify、Cloudflare Pagesなどへアップロードできます。
